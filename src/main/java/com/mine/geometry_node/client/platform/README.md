# 客户端宿主基础能力

这里适配工作目录、服务器身份、Minecraft 线程和操作系统，不承载具体窗口或资产业务。不同功能需要同一宿主能力时从此处复用。

| 文件 | 职责与约束 |
| --- | --- |
| `ClientPaths` | 游戏工作根目录、`config/geometry` 配置与工作区会话文件的位置、相对路径解析和文件身份比较。游戏实例不可用时回退到工作目录。 |
| `ClientServerIdentity` | 当前连接/单人世界的服务器身份，供客户端缓存、工作区等进行隔离。不是服务端世界目录定位器。 |
| `ClientThread` | Minecraft 客户端线程执行入口；已经位于该线程时立即执行，否则入队。提供同语义的 Executor。 |
| `DesktopFileBrowser` | 调用宿主操作系统文件管理器定位文件/目录；不拥有资产列表或 UI 选择。 |

Minecraft 客户端线程与 ModernUI 线程不同。此目录的 `ClientThread` 不可替代 UI 回调调度；工作区和绘制桥接放在 `integration`。业务目录策略（本地草稿、预览缓存等）由对应功能在工作根目录之上定义。
