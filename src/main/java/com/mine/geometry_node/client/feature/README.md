# 客户端功能服务

按功能组织连接级数据、文档、请求、缓存和业务操作。这里的 feature 是职责命名空间，不代表所有功能都有相同的内部层次。

- `asset`：资产模型、目录仓库、文件操作、传输、预览产物与缓存。
- `datalibrary`：数据仓库访问契约、连接快照、修改与传输适配。
- `entity`：实体编辑请求、登记索引和外观快照；不负责窗口或实体绘制。
- `faction`、`worldquery`：各自的连接访问和查询能力。
- `graph`：图文档、修改命令、历史适配、文件所有权、查询及元数据。
- `scene`：场景修改、冲突、确认与历史。
- `ai`：命令协议、目录、校验和 MCP 传输；具体工作区和 ModernUI 的适配位于 `integration/ai`。
- `terminal`：终端会话、PTY、模拟器和进程能力；MCP 关联位于 `integration/terminal`。

功能之间可以通过明确契约合作，例如仓库使用资产传输、图文件使用资产结构事务。不得引用 `ui`、ModernUI、具体屏幕或 `integration` 实现。成功/失败通过结果和事件发布，由调用方决定展示方式。

世界资源生命周期和图形执行位于 `runtime`。通用线程、路径、操作系统能力位于 `platform`；不要为了消除一条 import 就复制实现或新增没有真实所有权的接口。
