# 客户端具体装配

本目录连接功能服务、运行时、UI 与 Minecraft/ModernUI 的具体宿主。它可以引用这些实现；功能服务和运行状态不能反向引用本目录。

- `asset`：工作区资产动作、图/文件属性接线，以及资产与缩略图缓存注册。
- `graph`：图文档调度、下载与真实布局策略的装配。
- `entity`：实体编辑组件与资产选择器、当前工作区图编辑器的连接。
- `runtime`、`model`：运行状态的屏幕呈现和模型 HUD 注册。
- `ai`：MCP/命令到当前文档、工作区 surface 与 UI 线程的适配。
- `terminal`：终端和 MCP 启动/取消/关闭的共同生命周期。
- `picker`：原版 Screen 选择会话与全局输入的连接。
- `game`：具体工作区宿主到运行时视口策略的连接。

只装配已有能力；不要在这里维护第二份业务快照、文档集合、历史、缓存或复制共享控件。异步任务仍由原有业务所有者管理，UI 挂载/失效检查由宿主适配负责。
