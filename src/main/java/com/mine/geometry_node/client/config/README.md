# 客户端设置扩展指南

设置由模型、注册元数据、事务与存储、UI 页面四层组成。新增设置优先扩展现有入口，不另建配置文件或逐窗口保存副本。

| 入口 | 职责 |
| --- | --- |
| `AppConfig` | 持久模型、默认值及深复制。未进入设置页的运行状态也可能位于模型中。 |
| `ConfigEntry` / `BuiltinConfigEntries` | 稳定 ID、读写函数、分类、翻译键、编辑器类型、可见性与规范化规则。 |
| `ConfigRegistry` | 注册、分类树、统一规范化与快捷键冲突查询。 |
| `ConfigSanitizer` | 按注册项读取 JSON；单独处理未注册的收藏、侧栏状态及必要的旧字段读取。 |
| `ConfigDraft` | 隔离的编辑草稿；应用时仅将修改过或明确重置的注册项合并到最新配置。重置意图在成功保存后清除，失败可重试。 |
| `ConfigManager` / `ConfigStore` | 先原子保存，再发布快照和通知；保存失败保留旧配置及待应用草稿。 |
| `ui/settings/editor` | 按元数据构建控件、输入校验、快捷键录入；不拥有磁盘存储。 |
| `ui/settings/page` | 页面注册、分类和搜索；专用页面可组合通用编辑器与服务操作。 |
| `ui/settings/window` | 草稿生命周期、跨页校验、应用、放弃确认及弹层清理。 |

## 新增设置

1. 在 `AppConfig` 中增加字段、默认值和 `copy()` 支持。
2. 注册 `ConfigEntry`，ID 必须与 JSON 路径一致，例如 `previewCache.location`；提供类型、规范化规则和翻译键。普通注册项不需要修改 JSON 加载分支。
3. 补齐中英文标签、描述及枚举选项翻译。可见设置通过页面投影确定唯一归属；隐藏项仍参加持久化及校验。
4. 使用 `ConfigManager.get/set` 或草稿 API 读写；UI 编辑过程不直接修改发布中的模型。运行时变更通过 `update` 提交完整候选快照。
5. 验证非默认值和未绑定值能往返保存；新增数据类型时同步扩展编辑器与 JSON 读取契约。

`BuiltinSettingsProjection` 集中定义内置页面的互斥归属：快捷键进入按键映射，预览缓存仅进入专用页，资产浏览器的其余设置进入路径页，剩余项进入参数页。使用分类的子树关系，不为每个页面另维护一份字段清单。

## 快捷键

- 复制、粘贴、剪切、删除、撤销、重做、保存、重命名和全选只注册在 `keyBindings.global`。各编辑器提供动作实现，绑定与动作作用域均使用 `GLOBAL`，不再保存上下文副本。
- `GLOBAL` 是当前宿主动作表的公共回退层，不是向所有窗口广播。各宿主仍负责文本焦点、加载状态和选择的有效性检查。
- 场景变换、飞行控制、图专用命令保留自己的作用域。`input/binding` 负责纯输入语义，`ui/shortcut` 负责 ModernUI 适配及分派。工具栏和菜单提示从注册项读取当前绑定。
- 冲突检查遵循实际分派范围：普通上下文与通用命令重叠；飞行捕获会屏蔽通用命令，但仍处理视图菜单，因此单独检查菜单与飞行按住控制的组合冲突。
- 文本编辑、模态确认/取消和终端控制协议按各控件的输入语义处理；不要把协议键误注册成业务快捷键。

游戏连接内的临时界面状态与跨启动保存的布局状态使用 `ui/workspace/state` 的 MEMORY / PERSISTENT 存储；不要把业务数据和所有临时 UI 状态都加入 `AppConfig`。配置位置由 `ClientPaths` 统一提供，见上级目录的路径说明。

旧的上下文通用快捷键仅在共享项缺失、无效或仍为默认值时用于读取有效自定义值；明确自定义或取消绑定的共享项优先。多个旧自定义值冲突时，删除/全选优先读取图编辑器，再读取场景编辑器，最后读取旧平铺字段；保存后仅保留统一结构。
