# 游戏运行时

这里拥有游戏连接内的世界资源、游戏视口、渲染及运行会话；不拥有 ModernUI View、工作区 Area 或实际界面。它与 `feature` 都是客户端逻辑，但生命周期与资源责任不同，不必强行合成同一组 service/repository 层。

| 子目录 | 职责 |
| --- | --- |
| `game` | 工作区游戏视口的相机、输入、区块、世界渲染、帧调度及租约；见其 README 的线程/帧所有权。 |
| `model` | 模型加载与实例、GPU 渲染、资源生命周期、LOD、兼容和诊断状态。 |
| `light` | 客户端灯光状态、材质适配、世界渲染及诊断数据采集。 |
| `render` | 蓝图动态视觉效果、图片资产及调试几何/投影渲染。 |
| `behavior` | 行为树调试快照与监听者。 |
| `collision` | 服务端同步碰撞在客户端的状态与查询适配。 |
| `marker` | 标记快照、插值及只读渲染快照；HUD 绘制在 `ui/hud/marker`。 |
| `dialogue` | 对话会话、分页/商店动作与呈现协议；真实屏幕在 `ui/screen/dialogue`。 |
| `quest` | 任务屏幕快照、预览与呈现协议；真实屏幕在 `ui/screen/quest`。 |
| `cache` | 运行缓存和统一缓存注册体系的接线。 |

世界绘制属于运行时，并非所有绘制都应移动到 UI。反之 Canvas、控件、屏幕或 HUD 排版属于 UI。具体两端连接由 `integration` 安装：例如纹理发布桥、对话呈现、模型 HUD。接口应表述能力和所有权，不能返回 ModernUI 对象。

新运行资源须明确创建/更新/注销、断线和世界切换时的释放，必要时接入 `core` 的资源激活及缓存契约；禁止以窗口是否存在代替世界资源生命周期。Java 移包不能改变资源 ID、缓存路径和网络协议。
