# 客户端历史内核

图文档与场景编辑共同使用的撤销/重做状态机，不持有 View、Minecraft 世界或文件。业务适配器决定修改如何执行；此目录管理操作顺序与状态，不复制业务对象。

| 文件 | 职责 |
| --- | --- |
| `HistoryTarget` | 对外暴露某个业务所有者的历史状态、撤销/重做和订阅。 |
| `HistorySession` | 每个作用域独立的撤销/重做栈、revision、保存点与操作票据。预留、提交、失败和重置均由该会话校验。 |
| `HistoryOperation` | 一次操作的标识、阶段及最终异步结果。 |
| `HistoryResult` | 已应用、无变化、失败、作用域已关闭等结果，不负责通知界面。 |
| `HistoryState` | 不可变状态快照及可撤销/重做、dirty 和阻塞原因。 |

会话用 epoch 隔离 reset/close 前的旧票据；未知结果不能当作失败直接重复提交。通知期间不允许重入修改，订阅由使用者关闭。图的文档 claim/revision、场景的服务端确认仍归各业务模块；不要用历史状态代替它们。新业务应实现 `HistoryTarget` 并拥有自己的 `HistorySession`，UI 只订阅状态和发起动作。
