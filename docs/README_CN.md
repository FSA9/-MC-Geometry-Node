# GeometryNode

[中文](README_CN.md) | [English](../README.md)

GeometryNode 是一款面向 Minecraft 的可视化节点编程 Mod，目标是提供对标 Unreal Engine 蓝图和 Blender 几何节点的创作体验。

项目希望让创作者直接在游戏内通过节点图组织逻辑与数据，而不必为每一种玩法反复编写传统代码：

- 参考 UE 蓝图，使用事件、执行流、变量和动作节点构建游戏逻辑；
- 参考 Blender 几何节点，以程序化方式生成、组合和处理几何内容；
- 提供图编辑、保存、加载和运行时执行能力，让节点图真正参与 Minecraft 世界的交互与表现。

项目目前仍在开发中，节点接口、图数据格式和运行时架构可能继续调整。
