# GeometryNode

[中文](README_CN.md) | [English](../README.md)

GeometryNode 是一款面向 Minecraft 的游戏内可视化编程与内容创作 Mod，设计灵感来自 Unreal Engine 蓝图和 Blender 几何节点。它将玩法逻辑、实体行为、任务、对话、资产及配套开发工具整合到同一个节点编辑器中。

创作者无需为每一种交互单独编写 Mod，即可通过节点图搭建并迭代玩法系统。图资产可以直接在游戏内编辑、保存、加载、校验和运行。

## 主要功能

- **可视化图编辑器**：支持节点搜索、类型化端口、连线、分组、属性、可复用资产、撤销/重做以及编辑器内预览。
- **蓝图运行时**：通过事件、执行流、变量、条件、延迟和函数组织玩法，并提供面向玩家、实体、方块、物品、容器、世界及视觉效果的节点。
- **行为树与实体 AI**：使用选择器、序列、装饰器、条件、动作、同资产图组和黑板构建独立行为树资产；提供运行时调试，并能按能力协调 Minecraft 原生 `Goal` 与 `Brain` AI 的控制权。
- **任务系统**：定义任务信息、目标、条件、计数器、奖励和状态流转，保存玩家任务进度，并通过游戏内任务界面完成接取、提交与放弃等操作。
- **对话与商店**：创建带富文本和选项的分支对话，由服务端管理对话会话，并将对话流程、商店交易与图执行连接起来。
- **AI 辅助与 MCP**：通过仅监听本机且需要身份验证的 MCP 工具，让兼容的 AI 客户端读取编辑器和图状态、查询节点契约并提出可逆的图修改。修改会先经过 dry-run 校验和用户确认，再作为一次可撤销操作提交。
- **内置终端**：在编辑器中使用多个命令或 Shell 标签页；Windows 下支持基于 PTY 的交互式 PowerShell，并提供与 MCP 共用的图查询和编辑命令。
- **资产工作流**：浏览本地与远程资产，在客户端和服务端之间传输文件，预览图片与结构文件，并在编辑器中管理图资产。
- **几何与模型管线**：生成可用于世界操作的程序化几何数据，并通过模型导入、校验、GPU 资源管理和渲染管线加载自定义模型资产。
- **扩展 API**：通过插件式接口注册自定义节点、图值编解码器、标记、对话表现和编辑器集成。

## 当前适配

- Minecraft `26.1.2`
- NeoForge `26.1.2.75` 及以上
- ModernUI `3.13.0.5` 及以上
- Architectury API `20.0.7` 及以上
- Java `25`

## 开发状态

GeometryNode 仍在持续开发中。各项功能正在进一步集成和完善，节点 API、图数据格式、运行时行为及兼容性要求仍可能随版本调整。
